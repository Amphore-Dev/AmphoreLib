# Amphore Lib

### Install

1. Generate a new SSH key and add the public one to [your github settings](https://github.com/settings/keys)

2. Add this to an `.npmrc` file at the root of your project
    ``` css
    @amphore-dev:registry=https://npm.pkg.github.com
    ```
3. In your project folder, run:
	```
	npm install @amphore-dev/amphore-lib
	```
	or
	```
	yarn add @amphore-dev/amphore-lib
	```
